## Regression risks and remaining limits

- Administrative bootstrap now requires the local CLI command `php artisan admin:provision email@example.test`; only one main admin can be provisioned through it. Deployment procedures must include this explicit step.
- The group slug validation closes normal create/update collisions. A simultaneous duplicate race remains protected by the database unique constraint and was not load tested.
- The contact limiter is intentionally scoped to contact submissions and keyed by IP. Registration and signup abuse controls remain outside D-006 and should receive separate policy and testing.
- Newsletter DB-failure and successful-replacement paths were verified. Other asset controllers and filesystem hardware failures remain part of the 75 unexecuted cases.
- D-009 prevents unauthorized preference writes; it did not previously expose foreign event data because reads were already scoped.

No production incident is asserted by these isolated reproductions.
